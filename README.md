# Degen Stablecoin Sim (Very High Risk)

Public dashboard for Justin's **very high-risk** paper-trading stablecoin yield simulation, targeting 25%+ blended APY.

- No real funds, wallets, or transactions.
- Completely separate from the [low-risk book](https://jtncr.github.io/yield-sim-dashboard/) and the [higher-risk ~12% book](https://jtncr.github.io/yield-sim-highrisk-dashboard/).
- Regenerated and pushed on every simulator `update` cycle.
- Live page: https://jtncr.github.io/yield-sim-degen-dashboard/
